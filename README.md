# דיווח קילומטראז' רכבי חברה

אפליקציית ווב לניהול דיווחי קילומטראז' של רכבי ליסינג בחברה, מיועדת לקצין הרכב ולעובדים המדווחים.

## תכונות

- **התחברות מרובת משתמשים** — לכל עובד שם משתמש וסיסמה נפרדים.
- **קצין רכב (מנהל):**
  - מסך ראשי המציג טבלת כל העובדים עם שם פרטי, שם משפחה, מספר רכב, יצרן ודגם, שנת ייצור, תאריך תחילת חוזה הליסינג, טלפון ומייל.
  - הוספה, עריכה ומחיקה של עובדים — כולל בחירת יצרן ודגם הרכב מרשימה נפתחת (הדגמים מתעדכנים לפי היצרן שנבחר).
  - ייבוא עובדים בכמות מקובץ אקסל (עם קובץ תבנית להורדה).
  - שליחת קישור דיווח אישי לכל עובד דרך וואטסאפ (נפתח WhatsApp עם הודעה מוכנה) או מייל (נפתחת תוכנת המייל עם הודעה מוכנה), וכן אפשרות להעתיק את הקישור או לאפס אותו.
  - צפייה בכל דיווחי הקילומטראז' של כל עובד, כולל תאריך הדיווח ומועד השליחה בפועל.
- **עובד:**
  - צפייה בפרטי הרכב שהוקצה לו.
  - שליחת דיווח קילומטראז' חדש (תאריך + קריאת קילומטראז') — דרך המערכת (עם התחברות) או דרך הקישור האישי שנשלח לו (ללא צורך בהתחברות, מתאים לנייד).
  - צפייה בהיסטוריית הדיווחים האישית שלו.

הנתונים נשמרים בקובץ `data/db.json` (נוצר אוטומטית בהפעלה הראשונה).

## התקנה והרצה

דרוש [Node.js](https://nodejs.org/) גרסה 18 ומעלה.

```bash
npm install
npm start
```

השרת יעלה בכתובת: http://localhost:3000

## התחברות ראשונית

בהפעלה הראשונה נוצר אוטומטית משתמש קצין רכב ברירת מחדל:

- **שם משתמש:** `officer`
- **סיסמה:** `officer123`

**חשוב:** מומלץ להחליף את הסיסמה הזו בעריכת הקובץ `data/db.json` (או להוסיף עדכון סיסמה למסך ההגדרות בעתיד) מיד לאחר ההתקנה, ולפני שימוש אמיתי בסביבת ייצור.

## הוספת עובדים

1. התחברו כקצין רכב.
2. במסך הראשי לחצו על "הוספת עובד".
3. מלאו שם פרטי, שם משפחה, מספר רכב, תאריך תחילת חוזה ליסינג, ושם משתמש/סיסמה לעובד.
4. מסרו לעובד את פרטי ההתחברות שנוצרו עבורו.

## דיווח דרך וואטסאפ / מייל

לכל עובד יש קישור דיווח אישי (`/report/<token>`) שלא דורש התחברות — מתאים לשליחה בוואטסאפ או במייל כדי שהעובד ידווח קילומטראז' תוך שניות מהנייד.

- **וואטסאפ:** בטבלת העובדים במסך הראשי יש כפתור "וואטסאפ" שפותח הודעה מוכנה עם הקישור, וקצין הרכב לוחץ "שליחה" בפועל. **אין שליחה אוטומטית ברקע** — וואטסאפ לא מאפשר לעסק לשלוח הודעה ראשונית אוטומטית בלי חשבון WhatsApp Business API מאושר (דרך Meta או ספק כמו Twilio/360dialog), הכולל אימות עסקי, תבניות הודעה מאושרות מראש, ולרוב עלות לפי הודעה.
- **מייל:** יש גם כפתור "מייל" לשליחה ידנית, **וגם שליחה אוטומטית חודשית** — ראו הסבר בהמשך.

הקישור האישי מהווה בפועל "מפתח כניסה" לדיווח עבור אותו עובד — אין לשתף אותו בפומבי. אם קישור דלף או נשלח בטעות, ניתן לאפס אותו בלחיצת כפתור בטבלת העובדים (זה מבטל את הקישור הישן).

## תזכורות מייל אוטומטיות (חודשי, דרך M365/Outlook)

האפליקציה יכולה לשלוח אוטומטית ב-1 לכל חודש, בשעה 08:00, מייל תזכורת לכל עובד עם כתובת מייל מוגדרת, עם קישור אישי לעדכון קילומטראז'. השליחה מתבצעת דרך תיבת Outlook/M365 של החברה (SMTP), ולכן צריך להגדיר אותה:

### שלב 1: לוודא/להפעיל SMTP AUTH בתיבה

ב-M365 חסום כברירת מחדל שליחת מייל דרך SMTP רגיל (Basic Auth) לכל תיבה, מסיבות אבטחה. יש לבקש ממנהל ה-IT / מנהל ה-Microsoft 365 של החברה להפעיל את זה לתיבה הספציפית שתשמש לשליחה (**Exchange Admin Center → Recipients → Mailboxes → [התיבה] → Manage email apps → Authenticated SMTP**). אם יש בתיבה חובת אימות דו-שלבי (MFA), יהיה צורך גם ב"סיסמת אפליקציה" (App Password) ייעודית לחשבון הזה במקום הסיסמה הרגילה.

### שלב 2: להגדיר את משתני הסביבה

העתיקו את הקובץ `.env.example` לקובץ בשם `.env` (באותה תיקייה) ומלאו אותו לפי הפרטים שקיבלתם מה-IT:

```
SMTP_HOST=smtp.office365.com
SMTP_PORT=587
SMTP_USER=fleet-officer@yourcompany.com
SMTP_PASS=הסיסמה-או-סיסמת-האפליקציה
MAIL_FROM=fleet-officer@yourcompany.com
APP_BASE_URL=http://localhost:3000
```

**חשוב:** הקובץ `.env` לא נשלח ל-GitHub (הוא ב-`.gitignore`) ומכיל סיסמה — אין להעביר אותו הלאה או לצרף אותו לשום מקום משותף.

לאחר עדכון ה-`.env`, יש להפעיל מחדש את `npm start` כדי שהערכים ייטענו.

### שלב 3: להפעיל/לבדוק

- אם ההגדרה הצליחה, במסך הראשי יופיע כפתור "שליחת תזכורות עכשיו" — אפשר להשתמש בו לבדיקה מיידית בלי לחכות ל-1 לחודש.
- אם משתני הסביבה לא מוגדרים, יופיע במקום זה הודעה שהתזכורות לא הופעלו.

### מגבלה חשובה: השרת חייב לרוץ ברציפות

התזמון האוטומטי (ב-1 לכל חודש) פועל רק כל עוד תהליך השרת (`npm start`) **רץ באותו הרגע**. אם האפליקציה רצה רק על המחשב האישי שלכם וסגור באותו יום — התזכורת לא תישלח. כדי שזה יעבוד בפועל בכל חודש, מומלץ להעלות את האפליקציה לשירות אירוח שרץ 24/7 (למשל Render או Railway).

## ייבוא עובדים מאקסל

במסך הראשי, "ייבוא מאקסל" מאפשר להעלות קובץ xlsx עם רשימת עובדים בבת אחת. יש להוריד את קובץ התבנית מהעמוד ולמלא אותו לפי העמודות (שם פרטי, שם משפחה, מספר רכב, יצרן, דגם, שנת ייצור, תחילת חוזה ליסינג, טלפון, מייל, שם משתמש, סיסמה). שם משתמש וסיסמה חובה לכל עובד כדי שיוכל להתחבר גם דרך המערכת המלאה.

## הערות טכניות

- הפרויקט בנוי עם Node.js, Express ו-EJS, ללא תלות בבסיס נתונים חיצוני.
- הסיסמאות מאוחסנות מוצפנות (bcrypt).
- לסביבת ייצור מומלץ להגדיר משתנה סביבה `SESSION_SECRET` עם ערך סודי וייחודי, ולהגיש את האתר מאחורי HTTPS.
